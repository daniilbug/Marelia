## Основа
Основа геймплея - перемещение во все 4 стороны, перенос предметов и взаимодействие с окружением.
Игрок исследует мир, занимается фермерством и созданием вина, посещает локации и общается с персонажами.

## Посещение локаций
Игрок может взаимодействовать с дверями домов, куда у него есть доступ, тем самым переходя во внутренню часть дома.
Внутренняя часть - отдельный уровень игры, в котором могут быть комнаты и интерьер дома.
Т.е внутренняя часть дома не является частью внешнего мира, переход не является бесшовным и происходит через взаимодействие с дверью или другим объетом для входа.
