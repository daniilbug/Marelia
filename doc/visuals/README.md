## Описание графического стиля
Визуал игры предполагает pixel art с довольно низким разрешением. 
Тем не менее, нужно оставлять какие-то важные детали на спрайтах.
Предметы и фасады домов должны отражать идею города и его окружений. 
Ориентироваться нужно в первую очередь на итальянские небольшие города и деревни.
Референсы для городка можно посмотреть в `./references`.

## Создание спрайтов
Спрайты создаем исключительно с помощью python скриптов, т.е через код с рисованием графических примитивов, а не через какие-то другие способы генерации.
Сами скрипты нигде в проекте не сохраняем. Используем только для временной генерации, пока спрайт не будет согласован.
Элементы сцены и их спрайты должны быть правильных пропорций.
Например: размер холодильника должен быть выбран пропорционально росту персонажа, т.е где-то 1.5 от роста персонажа.
Каждый спрайт должен быть согласован перед использованием в игре!
Важно:
	- нужно соблюдать симметрию там, где это возможно. Хочется видеть симметричные спрайты, хотя бы по горизонтали
	- нужно искать визуальный референс (нигде его в проекте не сохранять), перед создванием спрайта, чтобы рисовать реалистично
	- еще раз - очень нужно соблюдать пропорции при создании спрайтов, сравнивать спрайты с другими и принимать их по размеру
	- направление объектов может быть одним из четырех (влево, вправо, вниз, вверх), диагональные направления или под другим углом не используем

## Визуал комнат и зданий
Для зданий отдельно рисуется фасад и внутренняя часть.
Для комнат и зданий должны быть хорошо видны передняя и задняя стены, они должны быть достаточно высокими (точно выше игрока).
Боковые стены выглядят как небольшой узкий отрезок спрайта стены, удлиненный вверх во весь размер комнаты / здания.
Все спрайты стен, поверхностей пола и крыши делаются как квадраты с растягиванием через repeated.
Внутри комнат и зданий тоже хочется видеть некую симметрию размещения объектов, но без перегиба.
Нижнюю стену для помещения (внутренней части локации) рисуем со статичной прозрачностью 0.1, оставляем видимой только дверь для выхода.

## Частые проблемы
Есть ряд проблем при создании спрайтов, которые вознимают достаточно часто, и которых допускать нельзя:
	- спрайты для дверей выглядят не пропорционально и открытые / закрытые спрайты никак не связаны (например, дверь двойная, а спрайт открытой двери этого никак не отражает)
	- область над дверью должна быть той же стеной, что и слева / справа от двери, вырез пространства из двери происходит с помощью шейдера
	- объекты, которые должны висеть на стене, должны быть на стене, а не где-то ниже / выше
	- визуальное направление объектов (например, стульев) должно быть корректным с точки зрения композиции сцены (например, стулья направлены в сторону стола, а не все вниз)
