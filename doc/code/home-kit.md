# Home Kit — мебель, декор и элементы дома

Набор использует одинаковое имя `home-kit` внутри общих папок проекта:

- `scenes/home-kit/` — готовые объекты;
- `scripts/home-kit/` — их поведение;
- `assets/home-kit/` — спрайты, маски, оформления и шейдер.

Общий компонент `TransparencyArea` используется из `core`.

Готовые сцены на согласованных спрайтах находятся в `scenes/home-kit/`.
Перетащите нужную `.tscn` в сцену комнаты и настройте её корень в Inspector.
Изменения видны прямо в редакторе благодаря `@tool`.

Для просмотра всей библиотеки откройте
`scenes/levels/home_kit_catalog/home_kit_catalog.tscn` и запустите через F6.
Main через F5 запускает пустой базовый уровень. Каталог — отдельный игровой
`Level`: при запуске через F6 он создаёт обычного игрока,
движение работает через WASD / стрелки, камера следует за игроком.
Границы уровня удерживают его внутри выставочного пространства.

В каталоге сохранены 75 образцов: оформления, направления и примеры разной
окраски экземпляров. Между образцами оставлены проходы; у мебели работают
коллизии, у крупных предметов — `TransparencyArea`. Настенные предметы висят
на стендах, настольные стоят на тумбах, труба установлена на образце крыши.
Стены стендов затухают вместе с закреплёнными на них предметами.

`exhibits.tscn` в папке уровня содержит размещение образцов, `display_wall.tscn` —
переиспользуемый внутри каталога стенд. Уровень использует общую основу `Level`
без отдельной реализации движения или создания игрока. Поверхности
используют согласованные квадратные текстуры с повторением из
`assets/home-kit/sprites/surfaces/`.

## Настройки экземпляра

- **Design → Style** — экспортируемый enum с осмысленными названиями оформлений.
  Отдельные варианты есть у кроватей, тумбочек, шкафов, комодов, диванов, кресел,
  стульев, столов и кухонных модулей. У навесного шкафа, полки и книжного шкафа
  можно выбрать пустой вариант или вариант с посудой / книгами.
- **Facing → Direction** — Down / Up / Left / Right у стула, кресла и дивана.
  Используются согласованные рисунки каждого направления.
- **Material colors** — независимые цвета дерева, краски / металла, ткани,
  штукатурки, камня и черепицы. Inspector показывает только материалы, которые
  встречаются в оформлениях данного предмета. Выбранные цвета сохраняются
  при переключении оформления и направления.
- **Geometry** — смещение рисунка, включение коллизии, собственная форма
  основания и её смещение. Без `Footprint Shape` используется основание
  выбранного рисунка; для собственной формы `Footprint Offset` задаёт её центр.
  Размеры пользовательской формы код не меняет.
- **Transparency** — настройки затухания у кровати, шкафа, дивана,
  холодильника, книжного шкафа и камина. Они используют общий `TransparencyArea`.
  У мелких предметов компонента и этой группы настроек нет.
- **Fire** у камина — `Burning` и `Animation Speed`. Огонь использует 12
  согласованных кадров с частотой 10 FPS; выключение оставляет рисунок
  погашенного камина. Окраска корпуса не затрагивает пламя.

Для ручной зоны у крупного предмета задайте `Transparency Shape` на корне
и её центр через `Transparency Offset`. Без собственной формы зона строится
за основанием, не шире предмета, и следует за его направлением.
При правке дочернего `TransparencyArea` включите Editable Children:
изменённые форма, позиция, масштаб и поворот сохраняются. При следующем
обновлении оформления ручная форма дополнительно переносится в настройки
корня. Автоматические формы помечаются метаданными; изменение их размера
делает их ручными. Чтобы вернуться к автоматической форме, очистите
соответствующий `Shape` на корне и обнулите его `Offset`. Собственные формы
помечаются как Local to Scene для независимой настройки экземпляров.
Параметры прозрачности меняйте на корне.

Настенные предметы и ковёр по умолчанию не блокируют движение. Ковёр и
входная ступенька лежат ниже мебели по `z_index`. Точка `(0, 0)` предмета —
его опора на полу; размещение на стене или на столешнице задаётся позицией
экземпляра в комнате. Не нужно растягивать спрайты для изменения цвета.

## Состав библиотеки

39 готовых типов, 63 оформления (включая пустые полки и погашенный камин),
90 рисунков с учётом направлений:

| Группа | Сцены |
| --- | --- |
| Спальня | `bed`, `bedside_table`, `wardrobe`, `dresser` |
| Сиденья и столы | `sofa`, `armchair`, `chair`, `coffee_table`, `dining_table`, `desk` |
| Кухня | `kitchen_base`, `kitchen_sink`, `cooker`, `fridge`, `wall_cabinet`, `wall_shelf`, `cooker_hood`, `kitchen_cart`, `sideboard` |
| Хранение | `bookcase`, `laundry_basket`, `coat_rack`, `shoe_bench`, `storage_chest` |
| Интерьер | `fireplace`, `washstand`, `table_lamp`, `wall_sconce`, `wall_mirror`, `wall_clock`, `rug`, `potted_plant`, `flower_vase`, `wall_painting` |
| Снаружи дома | `exterior_lantern`, `mailbox`, `window_flower_box`, `entrance_step`, `chimney` |

`chimney` — отдельный необязательный предмет; библиотека не добавляет трубы
к фасадам автоматически.

## Устройство

Общая основа — `furniture_piece.tscn` и `scripts/home-kit/furniture_piece.gd`.
`occluding_piece.tscn` добавляет компонент прозрачности для крупных предметов.
Скрипты конкретных семейств задают типизированные enum; данные оформлений
лежат в `assets/home-kit/designs/` как ресурсы `FurnitureDesign` / `FurnitureView`.
Они содержат спрайт, маску материалов, согласованный цветной оригинал,
смещение, основание и данные анимации.

Шейдер `assets/home-kit/shaders/furniture_palette.gdshader` восстанавливает четыре
ступени теней и света из нейтрального спрайта. Маска отмечает материал
каждого пикселя; стекло, книги, фурнитура, цветы и другие фиксированные детали
сохраняют цвет. Каждый экземпляр получает собственный `ShaderMaterial`.
Шейдер учитывает прозрачность спрайта и родительских узлов.

В проект перенесены только согласованные игровые PNG и маски; эскизы,
листы согласования и скрипты рисования остаются вне проекта.
